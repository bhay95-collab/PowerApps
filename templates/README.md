# Templates

Starters for a new STARS phone app or screen. Generated by `tools/templates/build_templates.py` from the same helpers as the DTV app.

| File | Screen name | Contains |
|---|---|---|
| `App_Formulas_Starter.txt` | — | Paste into App > Formulas first. Colours, font, header art, sizing, who-am-I, email look |
| `Template_Home.pa.yaml` | `TemplateHome` | Big header, hero card, progress card, tiles |
| `Template_List.pa.yaml` | `TemplateList` | Search, filter pills, count, empty state, gallery rows with status stripe (demo data in OnVisible) |
| `Template_Form.pa.yaml` | `TemplateForm` | Yes/No + "why not" pills + notes, multi-select chips, notes card, sticky submit with save |

## Try them (new blank app)
1. Create a blank **Phone** app (or a copy of an existing app to keep connections).
2. Settings → Display: Scale to fit **Off**, Lock aspect ratio **Off**.
3. Tree view → **App** → property drop-down → **Formulas** → paste all of `App_Formulas_Starter.txt`. Delete the `MeDirectory`/`MyDiscipline`/`IsManager` lines if `ClinicianDirectory` isn't connected.
4. For each template: + New screen → Blank → rename exactly (`TemplateHome`, `TemplateList`, `TemplateForm`) → right-click → **Paste code**.
5. `TemplateForm` save points at `MyList` — red until you replace it with a real list and its columns.

## Use one for real
Change screen name, control suffix (`_Hom`/`_Lst`/`_Frm`), text, data — in `build_templates.py` (copy it), not by hand. Re-run, validate, paste.
